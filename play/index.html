Straight to a fight: on the title menu, highlight NEW GAME and press SELECT (Backspace), not A. In the field, hold L + R (A + S) together. Hold Tab to fast-forward.

On a fresh save, highlight NEW GAME and press SELECT for the practice team. In the field, press L + R together to start a practice fight. Touch screens get on-screen buttons.

Saves and privacy

Save in the game's field menu as usual; the save is kept in this browser. The emulator also keeps a resume point, so closing the tab picks up where you left off. Use Export save to keep a copy, and Import save to continue an adventure from another emulator.

No account, no server: this page is static files. The only network requests are this page, the emulator, and the sprite sheets from SpriteCollab the first time, each checked against the tested release.
