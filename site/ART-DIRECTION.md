# Visual direction — minimal redesign

Reference: [Downwell](https://downwellgame.com/). Its official stylesheet uses
pixel typography, stark contrast and flat shapes. We borrow those principles,
not its artwork, logo, source code or copy.

The page is ivory `#f4f2e9`, ink `#17181c` and cobalt `#2948df`. Tiny5 provides
the pixel headline, hosted locally under its included SIL Open Font License.
One title, one sentence, one large borderless video; Download demo and GitHub
repo are adjacent, equally easy to find. All feature cards, statistics, extra
headings and rounded containers have been removed.

## Current social card

Saved asset: `public/og.png`. Generated with the built-in ImageGen tool on
12 September 2026 and inspected for text accuracy. No generated gameplay.
The previous card remains recoverable in Git history.

Final generation prompt:

> Use case: ads-marketing. Asset type: complete landscape social sharing card for the redesigned Emerald Arena website, approximately 1.91:1. Create one cohesive finished typographic design, not a website mockup. Primary request: bold minimal indie game identity matching a flat ivory web page with black pixel typography and electric blue square buttons. Palette strictly warm ivory #f4f2e9, near-black #17181c, electric cobalt #2948df. Wide generous ivory background, huge crisp blocky pixel lettering reminiscent of Tiny5: exact headline 'EMERALD ARENA' as the dominant element, comfortable margins, deliberately simple and forceful. One smaller secondary line only, exact text: 'Pokémon Emerald. Modified for real-time battles.' Use dark ink for legibility, one restrained cobalt rectangular underline or color accent. This is real modified GBA gameplay, but do not invent or depict gameplay: NO Pokémon illustrations, NO screenshots, NO forest artwork. No buttons, badges, rounded cards, shadows, gradients, decorative textures, logos from other games, watermarks, domain names or any additional copy. All typography English, exactly spelled. Flat sharp pixel geometry, high contrast, editorial spacing, clear at small link-preview size.
